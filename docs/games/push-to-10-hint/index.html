하는 법

기본 규칙은 밀어서 10과 같아요. 줄을 밀어서 3개 이상 붙은 합을 10으로 만들면 터져요. 블록을 톡 누르면 판 위의 같은 숫자가 검게 표시돼서 계획 세우기가 쉬워요. 이 버전은 3개만 지워도 횟수가 1번 늘어나요.

만든 이야기

숫자가 많아지면 어디에 뭐가 있는지 찾기 힘들다는 생각이 들어서 만들었어요. 같은 숫자를 한눈에 볼 수 있으면 훨씬 덜 답답할 것 같았어요. 힌트가 있는 만큼 횟수를 받기 쉽게 바꿔서 어떤 느낌인지 실험 중이에요.
